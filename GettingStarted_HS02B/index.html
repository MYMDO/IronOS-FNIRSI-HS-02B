Getting Started — FNIRSI HS-02B

Доповнення до апстримного GettingStarted, з урахуванням заліза HS-02B цього форку. Про прошивку — Flashing/HS02B.

Що інше на HS-02B

  • Екран: кольоровий IPS 160×80 (ST7735), варіант UI color_160x80. За замовчуванням увімкнені детальні екрани (DETAILED_SOLDERING=1, DETAILED_IDLE=1).
  • Кнопки — 3 шт.: UP=PB4 (біля жала), DOWN=PB5 (біля хвоста), OK=PB3. IronOS-логіка: UP/DOWN — як +/A / -/B в апстримі; OK — окрема кнопка: коротке натискання — вхід/підтвердження, довге — назад.
  • Живлення: DC + PD (CH224K, запит фіксовано 20 В). QC — немає апаратно. Ліміт потужності 60 Вт за замовчуванням, макс. 100 Вт (POWER_LIMIT / MAX_POWER_LIMIT).
  • Жало: картриджі C210 (2.5–2.7 Ом). Холодний опір у прошивці TIP_RESISTANCE 26 (×0.1 Ом).
  • PID під C210: TIP_PID_KP 40, TIP_PID_KI 700, TIP_PID_KD 4500, TIP_PID_INTEGRAL_LIMIT_SCALE 30.
  • Сон: акселерометр KXTJ3 (чутливість SENSITIVITY 7 за замовч.). Температура сну SLEEP_TEMP 150 °C, час сну SLEEP_TIME 5 (×10 с = 50 с), вимкнення SHUTDOWN_TIME 10 хв. Рух або будь-яка кнопка будять паяльник.
  • Бузер: зібраний, але гучність за замовч. 0 (BUZZER_VOLUME 0) — вмикається в меню.
  • Підсвітка кнопок: увімкнена на старті (BUTTON_BACKLIGHT 1).
  • Яскравість LCD: 1–105, крок 13, за замовч. 105.

Home screen

Home — точка входу:

  • UP — soldering (почати гріти до SOLDERING_TEMP 320 °C);
  • DOWN — settings menu;
  • у soldering: UP/DOWN коротко — ±1 °C; UP довго — Boost до BOOST_TEMP 420 °C, поки утримується; DOWN довго — вихід у standby;
  • у standby: UP довго — встановлення температури до нагріву; DOWN довго — debug menu;
  • обидві довго — lock кнопок (LOCKING_MODE 0 за замовч. — вимкнено).

OLED burn-in захисту як такого немає (IPS), але екран гасне при простої — рух/кнопка будять.

Debug menu → Tip Cal

17-та сторінка debug menu (з home — довге утримання UP) показує заводське калібрування зі стокової сторінки 0x0801F800: три counts + In Use (знайдено валідне) / Unused 26uV/C (fallback). Увага: довільний ASCII у цьому UI може рендеритись «кракозябрами» — малий шрифт містить лише гліфи з перекладів, текст треба проводити через make_translation.py.

Якщо щось не так

  • X замість жала — перевстановіть картридж C210 до упору.
  • Попередження про акселерометр/PD після першого старту — див. HardwareIssues, але на HS-02B це зазвичай наслідок живлення 5 В (PD ще не домовився / слабкий БЖ).
  • Температура «пливе» — перевірте Tip Cal (In Use?), БЖ на 20 В PD ≥60 Вт, потім — калібрування по термометру жала (див. TODO.md / CLAUDE.md).
